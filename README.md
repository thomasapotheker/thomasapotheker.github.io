# Thomas Apotheker - research portfolio

A responsive, accessible static personal website for GitHub Pages. The page works without JavaScript, tracking, third-party fonts, or a build step.

## Updating the site

- Edit `index.html` to update the introduction and research summaries.
- Put project PDFs in `reports/` and add links under the relevant project.
- Update `assets/style.css` to change the appearance.

Use descriptive filenames such as `sidreasoner.pdf`. Link to files with relative URLs so the same site also works in a local preview.

## GitHub Pages

The intended repository is `thomasapotheker/thomasapotheker.github.io`.
Enable GitHub Pages from the `main` branch and the repository root.
The resulting personal website address is `https://thomasapotheker.github.io/`.
